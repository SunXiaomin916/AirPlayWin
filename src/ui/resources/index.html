AirPlayWin v1.0.2
Windows 原生 AirPlay / RAOP 音频接收器
把 Windows 电脑变成局域网无线音箱：iPhone、iPad 和 Mac 可以直接把音乐投放到本机的扬声器、耳机、USB DAC 或 HDMI 输出。
  • Classic AirPlay / RAOP：Apple Lossless（ALAC）与 L16 音频
  • 防爆音：所有启动/停止/切换都经过淡入淡出与安全静音
  • 低延迟：IAudioClient3 / 独占模式 + 自适应抖动缓冲
  • 手机音量自动同步到 Windows 音量合成器
  • 断线恢复、睡眠唤醒恢复、默认设备热切换
⚠ 兼容性声明：本软件是基于公开资料与开源参考实现的实验性兼容接收器，未经 Apple 官方认证；“AirPlay” 商标归 Apple Inc. 所有。仅建议在可信的专用局域网中使用（接收器采用开放认证）。
